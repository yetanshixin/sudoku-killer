求解技巧说明

一、基础技巧

唯一候选数：某空格只剩一个候选数字，直接填入。
隐性唯一：某数字在某行/列/宫中只能放在唯一一个位置，填入该位置。
显性数对：两个格子候选完全相同且只有两个数字，排除同单元其他格子的这两个数字。
隐性数对：两个数字在某单元中只能放在同样的两个格子，排除这两个格子的其他候选。
区块摒除：某数字在某宫中只能出现在同一行/列，排除该行/列其他宫的该数字。
区块交互：某数字在某行/列中只能出现在某宫，排除该宫其他行/列的该数字。
显性三数组：三个格子的候选并集恰好三个数字，排除同单元其他格子的这三个数字。
显性四数组：四个格子的候选并集恰好四个数字，排除同单元其他格子的这四个数字。
隐性三数组：三个数字在某单元中只能放在同样的三个格子，排除这三个格子的其他候选。

二、鱼类技巧

X-Wing：某数字在两行中恰好各有两个相同候选列，排除这两列其他行的该数字。
Swordfish：X-Wing 的三行三列版本——某数字在三行中候选集中在同样三列。
Jellyfish：X-Wing 的四行四列版本——某数字在四行中候选集中在同样四列。

三、链式技巧

XY-Wing：以候选 {X,Y} 的格子为枢纽，两翼分别为 {X,Z} 与 {Y,Z}，排除同时看到两翼的格子的 Z。
XYZ-Wing：XY-Wing 的扩展，枢纽格有 {X,Y,Z} 三个候选。
W-Wing：两个候选相同的双值格通过某数字的强连接相连，排除同时看到两者的候选。
Remote Pairs：候选 {X,Y} 的格子沿链交替，偶数长度链两端一 X 一 Y，排除看到两端的 X、Y。
XY-Chain：双值格沿强连接成链，链两端必有一个为某候选，排除同时看到两端的该候选。
X-Chain：单数字沿强连接着色（红绿），同色冲突或红绿可见时排除该数字。

四、唯一性技巧（依赖唯一解）

唯一矩形：四格矩形中三格 {X,Y}、一格 {X,Y,Z}，为避免产生多解，第四格不能是 X 或 Y。
BUG +1：除一格外所有空格都是双值，该格必须填"在行/列/宫都出现三次"的那个数字。

提示：逐步求解按技巧难度依次尝试；遇到需要「试错（猜数）」的极难题时，会如实提示而不会硬猜。
